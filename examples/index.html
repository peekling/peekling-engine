Local source examples

Learn the runtime in four steps

These pages use the runtime built from this checkout and a synthetic local Pack. Start with pointer following, then move through Events, host-mounted content, and the declarative lifecycle.

  1. Simple pointer-follow Plan One browser Event, one Rule, and motion plus State.
  2. Application job progress Typed Events update a surface while pointer motion continues.
  3. Generic interactive surface Host-owned DOM, async work, cleanup, and Event completion.
  4. Declarative Web Component Connect, disconnect, destroy, and remount behavior.
