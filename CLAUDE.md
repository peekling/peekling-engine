This folder is the self-contained public Peekling engine monorepo. Read
`AGENTS.md` before work. Website and reusable visual-system work belongs in the
separate web and design-system repositories.

Reader-facing website and documentation prose must not use em dashes or
semicolons. Rewrite with a comma, colon, or period. Required programming syntax
inside code blocks and code examples is exempt.

Do not read, import, link, or package files from the private parent workspace.
Keep character packs data-only and the runtime dependency-free. Do not commit,
push, publish, add remotes, or create accounts without explicit authorization.
